Step-by-step Wallet & CLOB key setup The dashboard can derive the CLOB keys for you
Use a dedicated MetaMask account with limited funds. Its private key gives complete control of that account. Never paste a Secret Recovery Phrase here, never share the key with another person, and close screen-sharing or recording software before revealing it.

MetaMask connected to Polymarket.com Typical existing account

Select signature type 2. Paste the address shown in Polymarket Settings ↗ into Funder / proxy address. This is normally different from the public address displayed in MetaMask because the funds are held by the account's Polymarket Safe.

0
Standalone MetaMask EOA Direct wallet trading

Select signature type 0 only when the trading funds are held directly at the MetaMask EVM address. Leave the funder field blank; the app will use the address derived from the private key. The wallet may need POL for Polygon gas.

  1. Choose the exact MetaMask account

    Open MetaMask and switch to the account that controls the Polymarket account or the standalone funds. Do not use a different account from the one originally connected to Polymarket.

  2. Copy the EOA public address

    Open the account selector, choose the three-dot menu, then Account details. Copy the Ethereum/EVM address beginning with 0x and paste it into Wallet address. This field is optional, but filling it lets the dashboard verify that the private key below belongs to the same account. Official address guide ↗

  3. Export that account's private key

    In Account details, select Private key, enter the MetaMask password, and hold to reveal it. Copy the individual account key beginning with 0x into EOA private key. Do not enter the 12/24-word Secret Recovery Phrase. Official export guide ↗

  4. Set the funder and signature type

    For the usual MetaMask-connected Polymarket account, copy the profile address from Polymarket Settings into Funder / proxy address and select 2 — legacy MetaMask / Polymarket Safe. Accounts using Polymarket's newer V2 deposit-wallet flow use type 3. For a standalone EOA, leave the funder blank and select type 0. The signer key, funder, and signature type must describe the same account structure.

  5. Let the dashboard create the CLOB credentials

    Keep Verify against Polymarket checked and leave the CLOB API key, secret, and passphrase fields all blank. Click Validate & save. The dashboard uses the private key for L1 authentication, creates or derives the three L2 values together, verifies them with Polymarket, and stores them locally. If you already generated credentials elsewhere, paste all three values—never only one or two. Polymarket authentication guide ↗

  6. Restart and verify before enabling live orders

    Restart the engine so it reloads the saved values, return to this tab, and use Check pUSD balance. Confirm the address and balance belong to the intended account before switching to Live mode. Saving credentials alone does not enable live trading.

Common setup errors
  • Private key derives a different address: the Wallet address came from a different MetaMask account. Switch accounts and repeat steps 2–3.
  • Invalid signature or funder: type 0/2 does not match where the funds live, or the Polymarket profile address was not used as the type-2 funder.
  • Partial CLOB credentials: clear all three L2 fields and derive them, or supply the API key, secret, and passphrase as one complete set.
Fastest option: leave all three CLOB fields blank
